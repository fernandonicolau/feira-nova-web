# Skills locais do Feira Nova Web

Estas skills registram decisões específicas deste produto. Elas foram adaptadas ao código real do Feira Nova; não carregam branding nem regras de negócio de outros projetos.

- `feira-nova-design-system`: orientar criação e revisão de componentes, tokens e layouts.
- `feira-nova-ux-review`: revisar acessibilidade, estados e qualidade visual antes de concluir mudanças de interface.

Use apenas a skill pertinente à tarefa. Regras comerciais e contratos da API continuam nas camadas de domínio e serviços, não nas skills.
